## Описание проекта
Реализация локального сетевого чата между двумя родственными процессами (`Host` и `Client`), созданными через `fork()`. Программа демонстрирует использование различных механизмов IPC для передачи данных и синхронизации.

### Сценарий: Локальный чат
- **Хост и клиент** обмениваются сообщениями в реальном времени.
- **Синхронизация:** Осуществляется с помощью POSIX семафоров (`sem_timedwait`) с таймаутом 5 секунд.
- **Мониторинг:** Хост отслеживает активность клиента. Если клиент не проявляет активности (отсутствие сообщений или heartbeat) более 60 секунд, хост завершает его работу сигналом `SIGKILL`.
- **Heartbeat:** Реализован фоновый обмен сигналами через отдельный FIFO-канал для контроля жизни процессов.

## Типы взаимодействия (реализованные TYPE_CODE)
1. **mq** (`POSIX Message Queues`): Основной канал чата.
2. **fifo** (`Named Pipes`): Канал для передачи Heartbeat-сигналов.
3. **sock** (`Unix Domain Sockets` / `socketpair`): Альтернативный канал связи.

## Особенности реализации
- **Дуплексная связь:** Для предотвращения "эха" (когда процесс читает свое же сообщение) реализовано разделение на два направленных канала: `Host -> Client` и `Client -> Host`.
- **Классовая структура:** Все типы взаимодействия наследованы от базового абстрактного класса `Conn`, что обеспечивает единство интерфейса (`Read`/`Write`).
- **Автоматизация:** Сборка осуществляется через `CMake` и скрипт `build.sh`, который автоматически генерирует исполняемые файлы для каждого типа взаимодействия.

### Системные требования
- ОС: Linux
- Компилятор: g++ (с поддержкой C++11 и выше)
- Утилиты: CMake, Make

### Сборка
```bash
chmod +x build.sh
./build.sh

### Запуск
После сборки будут созданы исполняемые файлы. Запуск требует прав sudo для работы с некоторыми системными ресурсами (очереди сообщений, семафоры):

```bash
sudo ./host_mq      # Чат через очереди сообщений
sudo ./host_fifo    # Чат через именованные каналы
sudo ./host_sock    # Чат через сокеты
Управление
- Введите текст и нажмите Enter для отправки сообщения.

- Введите exit для корректного завершения работы обоих процессов и очистки ресурсов.

### Обработка ошибок
Программа корректно обрабатывает:

- Превышение времени ожидания (таймауты семафоров).

- Неожиданное завершение одного из процессов.

- Ошибки создания/доступа к системным ресурсам IPC.
