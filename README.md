## Описание проекта
Целью работы является реализация и сравнение производительности двух типов потокобезопасных очередей на языке C++ с использованием библиотеки `pthread`.

### Реализованные структуры:
1.  **SCMP Wait-free Queue (Структура №7):** * **Тип:** Single Consumer, Multiple Producers (Один читатель, много писателей).
    * **Реализация:** Wait-free/Lock-free алгоритм на базе атомарных инструкций GCC (`__sync_lock_test_and_set`). 
    * **Особенность:** Не использует мьютексы для синхронизации, что минимизирует задержки при доступе нескольких писателей.
2.  **MCMP Locked Queue (Структура №8):**
    * **Тип:** Multiple Consumers, Multiple Producers (Много читателей, много писателей).
    * **Реализация:** Использование блокировок (`pthread_mutex_t`).
    * **Особенность:** Классическая реализация с монитором, обеспечивающая полную безопасность при любом количестве потоков.

## Тестирование и корректность
Программа включает встроенный тестовый стенд, который проверяет:
- **Целостность данных:** Каждое число из диапазона $[0, N-1]$ должно быть обработано ровно один раз.
- **Отсутствие гонок (Race Conditions):** Использование атомарного массива счетчиков для проверки каждого извлеченного элемента.
- **Производительность:** Замер времени выполнения операций для каждой структуры.

### Сценарии тестов:
- 1 Писатель, 1 Читатель (базовая проверка).
- 2 Писателя, 1 Читатель (проверка конкуренции писателей).
- 4 Писателя, 2 Читателя (проверка масштабируемости MCMP).
